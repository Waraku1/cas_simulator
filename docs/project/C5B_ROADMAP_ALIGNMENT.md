# C5B Roadmap Alignment

This change set corresponds to the C5 roadmap item `Performance evidence with C4 product UI/multiplayer load; preserve >=45 FPS target and >=30 FPS floor`.

It deliberately leaves the following roadmap items separate:

- C4D production D1 provisioning/binding/migration/rated smoke;
- production deploy/rollback evidence;
- school-local final regression evidence;
- browser/device final QA;
- final visual sign-off;
- CAS evidence packaging.

Those gates should be closed after C5B instrumentation is merged and real browser/device measurements have been collected.
